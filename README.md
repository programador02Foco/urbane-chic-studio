# Urbano Style Refresh

Refine a direção de arte do site Urbano Acessórios. Use https://piuka.com.br/ como referência de categoria e experiência de compra, sem copiar seu layout, identidade ou imagens. Quero uma loja de acessórios com personalidade de marca de moda: capa fotográfica impactante, campanhas editoriais, coleções visualmente distintas e catálogo de produtos com compra rápida. Reduza a aparência de template genérico, evite cartões repetitivos e crie um ritmo visual entre fotografias grandes, áreas claras, tipografia elegante e seções comerciais. Preserve a identidade própria da Urbano em azul-marinho e champagne. Priorize uma experiência mobile excepcional, animações suaves e imagens com enquadramento profissional.
